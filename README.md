# 🏕️ דירוג קייטנות – בית עמנואל רמת גן

אתר שבו כל תלמיד/הורה נרשם, רואה את **כל 53 הקייטנות של קיץ 2026**
של בית עמנואל ועיריית רמת גן, קורא מה אחרים כתבו על כל קייטנה,
ונותן ציון משלו מ-0 עד 10.

הפרטים של כל קייטנה – מקום, כתובת, תאריכים, שעות, כיתות, מחיר וטלפון –
נלקחו מתוך **חוברת קייטנות הקיץ של רמת גן 2026** ושמורים בקובץ `camps.json`.
אפשר לערוך אותם גם ישירות באתר, במסך "ניהול קייטנות".

## מה יש באתר

- **כניסה עם שם פרטי ושם משפחה** – מסך נפרד למשתמש קיים ולמשתמש חדש, בלי כפילויות שמות
  (הסיסמאות מוצפנות, לא נשמרות בטקסט גלוי).
- **דף בית** עם כל הקייטנות, ממוין מהציון הגבוה לנמוך, כולל חיפוש.
- **קריאת הודעות** – בעמוד כל קייטנה רואים את כל ההודעות שכתבו עליה, לפי הסדר,
  ולצד כל הודעה מופיע הציון שהכותב נתן.
- **כתיבת הודעות** – אפשר לכתוב כמה הודעות שרוצים על כל קייטנה (שאלות, טיפים, חוויות),
  ולמחוק הודעות שלך.
- **דירוג** – ציון 0–10 לכל קייטנה, ציון אחד לכל אדם, תמיד אפשר לעדכן או לבטל.
- **מסך ניהול** (רק למנהל): הוספה, עריכה ומחיקה של קייטנות, ומחיקה של הודעות
  וציונים לא ראויים – הכול ממקום אחד.

## איך זה עובד

1. במסך הראשון בוחרים: **"כבר יש לי משתמש"** או **"אני חדש כאן"**.
   משתמש חדש נפתח עם שם פרטי, שם משפחה וסיסמה. אי אפשר לפתוח שני משתמשים
   עם אותו שם פרטי + שם משפחה, וכניסה עם שם שלא קיים מקבלת הודעה ברורה.
2. מיד אחרי ההתחברות נוחתים ב**דף הבית**: כל הקייטנות של החופש הגדול, עם הציון
   הממוצע של כל אחת ומספר ההודעות. יש גם חיפוש.
3. לוחצים על קייטנה ונכנסים אליה: קוראים את כל ההודעות עליה, כותבים הודעה משלכם
   ונותנים ציון 0–10.
4. לוחצים על **"חזרה לדף הבית"** ונכנסים לקייטנה אחרת. וכך הלאה.

## מי כותב את ההודעות

**רק אנשים אמיתיים.** אין באתר תוכן שנוצר אוטומטית ואין הודעות אנונימיות:
כל הודעה וכל ציון שייכים למשתמש שנרשם בעצמו, והשם שלו מופיע לידם.
האתר מגיע ריק לגמרי – בהרצה הראשונה יש 0 משתמשים, 0 הודעות ו-0 דירוגים,
ורק רשימת הקייטנות מוכנה מראש.

## איך מריצים

**אין שום התקנה.** צריך רק Node.js מותקן במחשב (מ-https://nodejs.org).

1. פותחים את התיקייה.
2. **לחיצה כפולה** על `start.bat` (ווינדוס) או על `start.command` (מאק/לינוקס).
3. נפתח חלון שכתוב בו **"✅ הקייטנות רצות!"** – משאירים אותו פתוח.
4. הדפדפן נפתח לבד בכתובת http://localhost:3000

מי שמעדיף טרמינל: `node server.js` (או `npm start`) בתוך התיקייה. אין `npm install`,
אין חבילות חיצוניות – רק Node.

> ⚠️ **חשוב:** אי אפשר פשוט ללחוץ לחיצה כפולה על `public/index.html`.
> ככה הדף נפתח בלי שרת, הכניסה לא עובדת (הדפדפן יגיד `Failed to fetch`)
> ואין איפה לשמור את הדירוגים. תמיד נכנסים דרך `http://localhost:3000`.

הנתונים נשמרים בקובץ `data.json` שנוצר לבד בתיקייה – כל מי שנכנס לאתר
רואה את אותם דירוגים ואת אותן הודעות, וגם אחרי כיבוי המחשב הכול נשאר.

באינטרנט (ראו [DEPLOY.md](DEPLOY.md)) הכול נשמר במסד נתונים אמיתי במקום בקובץ,
פשוט על ידי הגדרת משתנה הסביבה `DATABASE_URL`.

## איך נהיים מנהל

במסך הכניסה לוחצים על **"אני מנהל הקייטנות"** וממלאים את קוד המנהל.
הקוד הוא:

```
1108
```

מומלץ לשנות אותו לפני שמעלים לאוויר:

```bash
ADMIN_CODE=הקוד-הסודי-שלכם node server.js
```

## איך מעלים לאוויר כדי שכל בית הספר ייכנס

**כל ההוראות נמצאות בקובץ [DEPLOY.md](DEPLOY.md)** – מדריך צעד אחר צעד עם כל
הלחיצות, בחינם ובלי כרטיס אשראי (GitHub + Neon + Render, בערך 20 דקות).

בקצרה: מעלים את הקבצים ל-GitHub, פותחים מסד נתונים חינמי ב-Neon, מחברים
ב-Render כ-Web Service עם משתנה הסביבה `DATABASE_URL`, ומקבלים כתובת אינטרנט.

## מבנה הקבצים

```
start.bat          – הפעלה בלחיצה כפולה בווינדוס
start.command      – הפעלה בלחיצה כפולה במאק/לינוקס
server.js          – השרת וה-API (Node בלבד, בלי חבילות)

```

## אם הכניסה לא עובדת

| מה קורה | הפתרון |
|---|---|
| מופיע `Failed to fetch` / `NetworkError` / "האתר לא מחובר לשרת" | השרת לא רץ, או שפתחתם את `index.html` בלחיצה כפולה. מפעילים את `start.bat` / `start.command` ונכנסים ל-`http://localhost:3000` |
| כתוב "הסיסמה לא נכונה" | הסיסמה שגויה. אם זה לא המשתמש שלכם – פותחים משתמש חדש עם שם משפחה שונה |
| כתוב "כבר קיים משתמש בשם…" | מישהו כבר נרשם עם אותו שם פרטי ושם משפחה – מוסיפים אות לשם המשפחה |
| כתוב "לא נמצא משתמש בשם…" | עוד לא נפתח משתמש כזה – לוחצים על "אני חדש כאן" |
| כתוב "הסיסמה חייבת להיות לפחות 4 תווים" | הסיסמה קצרה מדי |
| בחלון השחור כתוב "הכתובת 3000 כבר תפוסה" | השרת כבר רץ בחלון אחר – פשוט נכנסים לכתובת בדפדפן |
| בחלון השחור כתוב `'node' is not recognized` / `command not found` | Node.js לא מותקן – מתקינים מ-https://nodejs.org ומנסים שוב |

## ה-API בקצרה

| נתיב | מה עושה |
|---|---|
| `POST /api/register` | פתיחת משתמש חדש (שם פרטי + שם משפחה + סיסמה) |
| `POST /api/login` | כניסה למשתמש קיים |
| `GET /api/admin/feed` | כל ההודעות והציונים לניהול – מנהל בלבד |
| `GET /api/camps` | כל הקייטנות + ממוצע ציונים |
| `GET /api/camps/:id` | קייטנה אחת + כל ההודעות והציונים עליה |
| `POST /api/camps/:id/messages` | כתיבת הודעה על הקייטנה |
| `DELETE /api/messages/:id` | מחיקת הודעה (שלך, או כל אחת אם אתה מנהל) |
| `POST /api/camps/:id/reviews` | שליחת ציון 0–10 (מעדכן אם כבר נתת) |
| `DELETE /api/reviews/:id` | ביטול הציון |
| `POST/PUT/DELETE /api/camps` | ניהול רשימת הקייטנות – מנהל בלבד |
